Política de privacidad — Asistente

Aplicación de prueba privada · Última actualización: 26 de octubre de 2026

Qué es esta aplicación

Asistente es una aplicación de prueba privada, de uso exclusivamente personal, desarrollada y operada por Augusto Carlos Devesa (Buenos Aires, Argentina). No es un producto comercial, no está publicada al público, no se distribuye y no admite otros usuarios: funciona únicamente sobre la cuenta de Google de su propio autor, que es también quien la autoriza.

Qué datos de Google se acceden

Con la autorización OAuth del titular de la cuenta, la aplicación accede a los permisos estrictamente necesarios para ejecutar las tareas que ese mismo titular le pide:

  • Gmail — leer, enviar y clasificar correo.
  • Google Calendar — leer, crear y modificar eventos.
  • Google Drive — buscar, leer y organizar archivos.
  • Google Sheets y Docs — leer y escribir hojas de cálculo y documentos.
  • Google Contacts — sólo lectura de nombres, correos y teléfonos.
  • Perfil básico — correo e identificador de cuenta, para saber a qué cuenta pertenece el token.

Para qué se usan y dónde se guardan

Los datos se usan sólo para responder pedidos concretos del titular: resumir correo, redactar respuestas, gestionar agenda y documentos, organizar archivos. No hay perfilamiento, ni publicidad, ni analítica.

Las credenciales OAuth se guardan en un servidor propio del titular (instancia de Oracle Cloud Infrastructure) en archivos con permisos restringidos chmod 600. El contenido procesado vive en memoria durante la ejecución: no se construye una base de datos de correo ni de archivos, y no se hacen copias de respaldo de contenido de Gmail.

Con quién se comparte

Con nadie. No se venden, alquilan, ceden ni transfieren datos de usuarios de Google a terceros, no se usan para publicidad ni para entrenar modelos de terceros.

El uso y la transferencia que esta aplicación hace de la información recibida de las API de Google a cualquier otra aplicación cumple con la Política de Datos de Usuarios de los Servicios de API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

Conservación y eliminación

El acceso se mantiene mientras el titular quiera usarla. Se revoca en cualquier momento desde myaccount.google.com/permissions, lo que invalida los tokens de inmediato; el archivo de credenciales local se borra al revocar. Cualquier otro pedido de eliminación se atiende escribiendo a augustod@gmail.com y se resuelve dentro de 30 días.

Privacy policy (English)

Private test application · Last updated: October 26, 2026

Asistente is a private, personal-use test application developed and operated by Augusto Carlos Devesa (Buenos Aires, Argentina). It is not a commercial product, it is not publicly distributed and it has no users other than its author, who is the owner of the Google account that authorizes it.

With the account holder's OAuth authorization it accesses Gmail (read, send, label), Google Calendar (read and write events), Google Drive (search, read, organize files), Google Sheets and Docs (read and write), Google Contacts (read-only) and the basic profile (email and account id). The data is used only to execute the tasks that account holder requests; there is no profiling, advertising or analytics.

OAuth credentials are stored on a server owned by the account holder (an Oracle Cloud Infrastructure instance) in files with restricted permissions (chmod 600). Processed content lives in memory during execution; no mail or file database is built and no Gmail content backups are made. Google user data is not sold, rented or shared with third parties.

Asistente's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions. Other deletion requests: augustod@gmail.com (answered within 30 days). Contact: Augusto Carlos Devesa, Buenos Aires, Argentina.
