## Cómo se verificó esta lista

Cada una de las 20 URLs de abajo fue **abierta y comprobada** antes de entrar acá:

1. Respuesta HTTP 200 y contenido real de la publicación (no una página de error ni de búsqueda).
2. Extracción del `<title>` / `og:title` de cada página y cotejo contra el rol y la empresa.
3. Chequeo de marcadores de publicación vencida o cerrada.
4. Las publicaciones que dependen de JavaScript (Workday, Globant) se abrieron con un navegador real para confirmar que el puesto sigue activo.

Se partió de 42 candidatas y se descartaron las que no pasaron. Ejemplo: una publicación de Disney Careers en Buenos Aires **se descartó** porque su URL hoy redirige a una página de búsqueda genérica — el aviso ya no existe.
