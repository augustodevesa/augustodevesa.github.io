1. Quién es el responsable1. Who is responsible

Asistente es una aplicación de automatización personal desarrollada y operada por Augusto Carlos Devesa, con domicilio en Buenos Aires, Argentina. No es un producto comercial, no se ofrece a terceros y no se distribuye públicamente: la usa únicamente su autor sobre su propia cuenta de Google. Asistente is a personal automation application developed and operated by Augusto Carlos Devesa, based in Buenos Aires, Argentina. It is not a commercial product, it is not offered to third parties and it is not publicly distributed: it is used only by its author on his own Google account.

Contacto para cualquier consulta sobre esta política: augustod@gmail.com. Contact for any question about this policy: augustod@gmail.com.

  • Gmail — leer mensajes y metadatos, enviar y modificar etiquetas de correo.Gmail — read messages and metadata, send mail and modify labels.

3. Para qué se usan3. How it is used

Los datos se usan exclusivamente para ejecutar tareas que el titular pide por escrito al asistente: resumir correo, redactar y responder mensajes, consultar y crear eventos de agenda, leer y escribir documentos y planillas, y organizar archivos. No hay perfilamiento publicitario, ni análisis de comportamiento, ni decisiones automatizadas con efectos legales sobre ninguna persona. The data is used exclusively to carry out tasks the account holder requests in writing from the assistant: summarizing mail, drafting and replying to messages, reading and creating calendar events, reading and writing documents and spreadsheets, and organizing files. There is no advertising profiling, no behavioural analytics, and no automated decision-making with legal effects on any person.

4. Dónde se almacenan4. Where it is stored

Las credenciales OAuth (token de acceso y de refresco) se guardan en un servidor propio, una instancia de Oracle Cloud Infrastructure administrada por el titular, en archivos con permisos restringidos (chmod 600). El contenido que se procesa para responder un pedido vive en memoria durante la ejecución; no se construye una base de datos de correo ni de archivos, no se hacen copias de respaldo de contenido de Gmail y no se envía nada a servidores de terceros. OAuth credentials (access and refresh tokens) are stored on a server owned by the account holder, an Oracle Cloud Infrastructure instance he administers, in files with restricted permissions (chmod 600). Content processed to answer a request lives in memory during execution; no mail or file database is built, no Gmail content backups are made, and nothing is sent to third-party servers.

5. Con quién se comparte5. With whom it is shared

Con nadie. No se venden, alquilan, ceden ni transfieren datos de usuarios de Google a terceros. No se usan para publicidad, ni para entrenar modelos de terceros, ni para determinar solvencia o scoring. El único procesamiento externo es el que el propio titular elige al pedir una tarea, y los proveedores de modelo de lenguaje que el titular configura para esa tarea reciben únicamente el fragmento necesario para responderla. With no one. Google user data is not sold, rented, transferred or disclosed to third parties. It is not used for advertising, not used to train third-party models, and not used for credit or scoring purposes. The only external processing is what the account holder chooses when requesting a task, and the language-model providers he configures for that task receive only the excerpt needed to answer it.

6. Uso limitado6. Limited Use

El uso y la transferencia que Asistente hace de la información recibida de las API de Google a cualquier otra aplicación cumple con la Política de Datos de Usuarios de los Servicios de API de Google, incluidos los requisitos de Uso Limitado (Limited Use). Asistente's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Conservación y eliminación7. Retention and deletion

El acceso se mantiene mientras el titular quiera usar la aplicación. Se puede revocar en cualquier momento desde myaccount.google.com/permissions, lo que invalida los tokens de inmediato; el archivo de credenciales local se borra al revocar. Los pedidos de eliminación de cualquier otro dato se atienden escribiendo a augustod@gmail.com y se resuelven dentro de los 30 días. Access is kept for as long as the account holder wants to use the application. It can be revoked at any time from myaccount.google.com/permissions, which invalidates the tokens immediately; the local credential file is deleted on revocation. Requests to delete any other data are handled by writing to augustod@gmail.com and are resolved within 30 days.

8. Seguridad8. Security

El servidor se actualiza periódicamente, el acceso es por clave SSH (sin contraseñas), las credenciales tienen permisos de archivo restringidos y las claves privadas se guardan cifradas. Ningún empleado ni tercero tiene acceso a la cuenta. The server is patched regularly, access is by SSH key (no passwords), credentials carry restricted file permissions and private keys are stored encrypted. No employee or third party has access to the account.
